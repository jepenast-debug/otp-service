Configurar Autenticador

Protege tu cuenta con seguridad de dos pasos.

  1. Descarga Google Authenticator o Microsoft Authenticator en tu celular.
  2. Abre la aplicación y selecciona el ícono "+" para agregar una cuenta.
  3. Selecciona "Escanear código QR" y enfoca la imagen de la derecha.
  4. Ingresa el código de 6 dígitos que aparece en tu celular para verificar la vinculación.
